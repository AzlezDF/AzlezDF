## About Me

Saya Daffi Al Hammani, seorang Cyber Security Enthusiast yang tertarik pada keamanan siber, khususnya ethical hacking, keamanan jaringan, dan keamanan aplikasi web. Saya belajar secara konsisten melalui lab, platform CTF, dan proyek pribadi.

- 🔭 **Sedang dipelajari:** Web Application Pentesting, Network Security, Linux Privilege Escalation
- 🎯 **Fokus:** Penetration testing, vulnerability assessment, dan security fundamentals
- 🤝 **Terbuka untuk:** Kolaborasi, diskusi seputar keamanan siber, dan peluang magang/karier di bidang security
- ⚖️ **Etika:** Semua latihan dilakukan secara legal dan etis, hanya pada lab, platform CTF, atau sistem dengan izin tertulis.
